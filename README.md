# Expense Tracker

Личный учёт доходов и расходов в одной валюте.

## ЛР-1

Создано стартовое приложение на React, TypeScript и Vite.
На первом этапе отображается главная страница Expense Tracker.

## Требования

- Node.js
- npm

## Запуск

```bash
cd frontend
npm ci
npm run dev
```

## Проверка production-сборки

```bash
cd frontend
npm run build
npm run preview
```
